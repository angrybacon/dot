* Installation

If missing, create a desktop entry under =/usr/share/xsessions/= in order to
select Qtile as your preferred option from the login manager. The widgets rely
on decorations that are enabled through the =qtile-extras= package.

#+BEGIN_SRC conf
[Desktop Entry]
Name=Qtile
Comment=Qtile Session
Exec=qtile start
Type=Application
Keywords=wm;tiling
#+END_SRC

Install =mypy= and run =qtile check= in order to verify that your configuration
can be loaded safely. In addition, some widgets may depend on =psutil=.

In case of failure to reload the configuration through the predefined key
binding, Qtile can be reloaded from the command line directly.

#+BEGIN_SRC sh :results silent
qtile cmd-obj -o cmd -f reload_config
#+END_SRC

* Icon Overwrites

Some applications prefer the icon they ship with, ignoring the icon themes. We
install themes for a reason, so we reverse the priority. Tested with the Tela
theme.

#+BEGIN_SRC python
aliases = {
    'spotify-linux-32': 'spotify',
    'steam_tray_mono': 'steam',
}

_get_custom_icon = StatusNotifierItem._get_custom_icon

def _get_themed_icon(self, name, path):
    themed = self._get_xdg_icon(aliases.get(name, name))
    return themed or _get_custom_icon(self, name, path)

StatusNotifierItem._get_custom_icon = _get_themed_icon
#+END_SRC

* Groups

Install a Nerd Font font that comes with a /circle/ glyph and use that in group
labels. The current group is highlighted with text color so the same glyph can
be used everywhere.

#+BEGIN_SRC python
klasses: Dict[str, List[Union[str, Pattern]]] = {
    'full': ['dota2', compile('steam_app_(\\d+|default)')],
    'launcher': ['net.lutris.Lutris', 'steam', 'steamwebhelper'],
    'music': ['spotify'],
    'social': ['discord', 'slack'],
    'web': ['zen'],
}

groups_full = [Match(wm_class=klass) for klass in klasses['full']]
groups_launcher = [Match(wm_class=klass) for klass in klasses['launcher']]
groups_music = [Match(wm_class=klass) for klass in klasses['music']]
groups_social = [Match(wm_class=klass) for klass in klasses['social']]
groups_web = [Match(wm_class=klass) for klass in klasses['web']]

groups = [
    Group('1', label='\U0000F111', matches=groups_web),
    Group('2', label='\U0000F111', matches=groups_social),
    Group('3', label='\U0000F111', matches=groups_launcher),
    Group('4', label='\U0000F111', matches=groups_full),
    Group('5', label='\U0000F111'),
    Group('6', label='\U0000F111'),
    Group('7', label='\U0000F111'),
    Group('8', label='\U0000F111'),
    Group('9', label='\U0000F111', matches=groups_music),
    Group('0', label='\U0000F111'),

for g in groups:

        Key([mod], g.name, lazy.group[g.name].toscreen(toggle=True)),

class BorderedStatusNotifier(widget.StatusNotifier):
    def _draw_icon(self, icon, x, y):
        ctx = self.drawer.ctx
        size = self.icon_size
        ctx.save()
        ctx.arc(x + size / 2, y + size / 2, size / 2 + 1, 0, 2 * pi)
        ctx.set_source_rgba(*rgb(color_foreground))
        ctx.set_line_width(2)
        ctx.stroke()
        ctx.restore()
        super()._draw_icon(icon, x, y)

* Compositor

Start the compositor once per session. Reloading the configuration won't
relaunch it.

#+BEGIN_SRC python
@hook.subscribe.startup_once
def autostart():
    subprocess.Popen(['picom', '--daemon'])
