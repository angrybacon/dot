* Checklist

** Install Dependencies and Packages

#+BEGIN_SRC sh
brew install \
  btop fastfetch git ipython ncdu pnpm ripgrep tldr tree vim
#+END_SRC

#+BEGIN_SRC sh
brew install --cask \
  android-file-transfer ghostty gimp hiddenbar spotify steam vlc
#+END_SRC

** User Session

Add user paths.

#+BEGIN_SRC sh :tangle "~/.profile"
if [ -d "$HOME/.local/bin" ] ; then
  PATH="$HOME/.local/bin:$PATH"
fi

if [ -d "$HOME/Scripts" ] ; then
  PATH="$HOME/Scripts:$PATH"
fi

eval "$(/opt/homebrew/bin/brew shellenv)"
#+END_SRC

* Emacs

Install build dependencies, then install your preferred Emacs formulae.

#+BEGIN_SRC sh
brew install libgccjit tree-sitter
brew tap d12frosted/emacs-plus
brew install --cask emacs-plus-app
#+END_SRC

Most Emacs configurations also assume GNU utilities are available, in particular
=ls= since =dired= relies on it.
